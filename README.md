# Astral Drinks — GitHub Pages / PWA

Pacote final auditado com 21 arquivos, todos diretamente na raiz do repositório.

## Publicação
- Branch: `main`
- Pasta do GitHub Pages: `/(root)`
- Domínio: `www.astraldrinks.com.br`
- Não criar pasta `assets`.
- Não enviar o ZIP; extraia e envie os 21 arquivos.
- O CSS preserva a proporção original das artes (`width:100%` + `height:auto`).
- O Service Worker é registrado automaticamente pelo `app.js`.
- O botão Produtos aponta para `https://astral-drinks-produtos-qs8ow5g.gamma.site/`.
